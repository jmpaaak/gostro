# Gostro — Game Design

합의 (2026-09-07, game-idea-factory 기획 세션).

## 한 문장

화투 덱빌딩. **광 = 조커.** 플레이 패는 **단 / 고도리 / 피**만. 월 숫자는 버린다.

## 왜 고스톱인가

발라트로의 중독은 족보가 아니라 이 구조다.

```
약한 핸드 × (조커 +칩) × (조커 +배수) × (조커 ×배수) = 숫자 폭발
앤티가 그걸 따라오며 압박
```

블랙잭은 21이 천장. 포커는 이미 발라트로. 고스톱은 한국 고유 패 + 같은 폭발 구조를 탄다.

**앤티** = 난이도 단계. 앤티 1 스몰/빅/보스 → 앤티 2 … 앤티 8 보스 클리어가 승리. 조커를 모을수록 점수가 커지고, 목표 점수도 같이 커진다. 그걸 “앤티가 따라온다”고 한다.

## 패 — 복잡도를 버린 계약

1~12월, 송학/매화 같은 월 이름은 **표시하지 않는다.** 카드 얼굴은 종류만.

| 종류 | 시각 | 역할 |
|---|---|---|
| 광 | 큰 ★ | **조커.** 상점에서 사서 슬롯에 꽂는 패시브. 기본 기여 **1점** |
| 홍단 | **빨간 깃발** | 띠. 3장 = 홍단 |
| 청단 | **파란 깃발** | 띠. 3장 = 청단 |
| 초단 | **난초 모양** | 띠. 3장 = 초단 |
| 고도리 | **동물** (꾀꼬리·두견·기러기) | 3장 = 고도리 |
| 피 | 점 | 많이 모으면 피 점수 |

고도리 동물은 2·4·8월 새에서 오지만, 플레이어에게는 “동물 카드”로만 읽힌다.

## 족보 — 이것만

남긴다:

- 광 하나 = 1점 (기본 바닥)
- 홍단 / 청단 / 초단
- 고도리
- 피 (많이 모으면)

뺀다 (지어낸 포커 족보):

- 매 / 이매 / 삼매
- 뻑 / 쌍쓸
- 광열 콤보 / 오띠
- 비삼광 / 비사광 (광은 조커라 핸드 족보가 아님)
- 섯다 끗·땡·알리

이름 있는 역이 나와야 배수가 붙는다. 바닥은 칩 합 × 1.

## 광 = 조커

“고수패”라는 말은 쓰지 않는다. 발라트로 조커다. 이름만 광이다.

- 덱의 플레이 카드가 아니라 **슬롯에 꽂히는 패시브**
- 한 장 = 한 정체성 (칩+, 배수+, 특정 역 ×배수)
- 상점(도박장)에서 사고, 최대 5칸
- 150장 이상 확장 가능한 깊이. 수집 시스템으로 대체하지 않는다
- 광 기본 기여는 **1점**. 폭발은 시너지

## 루프

1. 핸드에서 단·고도리·피를 고른다 (최대 5장).
2. 플레이 = 칩 × 배수. 버리기로 패를 갈아탄다.
3. 라운드 점수 ≥ 블라인드 목표 → 클리어 → 상점.
4. 앤티 8 보스까지. 조커 시너지가 점수 천장을 연다.

플랫폼: LÖVE 11.5, 스켈레톤 기본 320×180 nearest-neighbor. 모바일 세로가 필요하면 이후 슬라이스에서 올린다.

## 첫 플레이 가능 목표

- `play → shop → next blind` 한 앤티
- 패 종류 6종만 그린다 (깃발/난초/동물/점/★)
- 족보 4종 + 광 1점 바닥
- 조커(광) 슬롯 구매
- 헤드리스 유닛 + smoke

## 에셋

카드 얼굴은 타이포·도형으로 충분. 월 일러스트·사람 스프라이트 금지. 종류가 한눈에 구분되면 된다.
