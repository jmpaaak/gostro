# Balatro UI Benchmark — Gostro 적용 참고

> 발라트로(Balatro) UI 레이아웃을 텍스트로 정리하고, 고스트로 320×180
> 해상도에 맞춘 변환 메모를 남긴다.

---

## (a) 메인 플레이 화면

### 발라트로 원본

```
┌──────────────────────────────────────────┐
│ [조커 슬롯 1~5]  (상단 가로줄)           │  ← 장착한 조커 카드 최대 5장
│                                          │
│ ┌────────┐                  ┌──────────┐ │
│ │ 점수판 │                  │ 블라인드  │ │  ← 좌상: chips × mult
│ │chips×  │                  │ 목표     │ │     우상: 블라인드 이름+목표 점수
│ │ mult   │                  │ 300      │ │
│ └────────┘                  └──────────┘ │
│                                          │
│          [플레이] [버리기]               │  ← 하단 중앙, 2버튼
│   ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐    │  ← 핸드 카드 8장 (하단)
│   └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘    │     선택된 카드는 위로 올라감
└──────────────────────────────────────────┘
```

- **핸드 카드**: 하단에 부채꼴/겹침 배열. 호버 시 위로 올라가며 확대.
  선택하면 고정으로 올라감. 최대 5장 선택.
- **조커 슬롯**: 상단 가로줄 5칸. 빈 칸은 점선 윤곽.
- **점수판**: 좌상단. "Chips × Mult" 두 줄 + 총점.
  핸드 플레이 시 칩과 배수가 순서대로 팝업되며 올라감.
- **블라인드 목표**: 우상단. 현재 블라인드 이름 + 목표 점수.
  프로그레스 바가 차오른다.
- **플레이/버리기 버튼**: 하단 중앙. "Play Hand" (파란) / "Discard" (빨간).
  남은 핸드 횟수와 버리기 횟수 표시.

### 발라트로 세부

- 핸드 카드 사이 겹침: 카드 폭의 약 60% 간격.
- 선택된 카드: 약 카드 높이의 20% 위로 올라감.
- 점수 연출: 칩 숫자가 먼저 표시 → "×" → 배수 숫자 → "=" → 총점이
  크게 팝업. 폰트 색: 칩=파란, 배수=빨간.

## (b) 상점 화면

### 발라트로 원본

```
┌──────────────────────────────────────────┐
│  [소지금: $7]                [팩 부스터] │
│                                          │
│  ┌──────┐  ┌──────┐  ┌──────┐           │  ← 진열 카드/조커 (2행까지)
│  │조커A │  │조커B │  │바우처│           │
│  │ $4   │  │ $6   │  │ $10  │           │
│  └──────┘  └──────┘  └──────┘           │
│                                          │
│  ┌──────┐  ┌──────┐                     │  ← 2행
│  │카드C │  │카드D │                     │
│  │ $3   │  │ $3   │                     │
│  └──────┘  └──────┘                     │
│                                          │
│     [리롤 $5]      [다음 라운드 →]      │
└──────────────────────────────────────────┘
```

- **진열**: 조커 2장 + 일반 카드/바우처 혼합. 2행 격자.
- **가격표**: 각 카드 하단에 달러 표시.
- **리롤**: 하단 좌측, $5. 누르면 진열 교체.
- **다음 라운드**: 하단 우측. 상점 종료 → 블라인드 선택.
- **소지금**: 상단 좌측에 달러 잔액.

## (c) 블라인드 선택 화면

### 발라트로 원본

```
┌──────────────────────────────────────────┐
│              ANTE 3                      │
│                                          │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │  SMALL   │ │   BIG    │ │  BOSS    │ │
│  │  300     │ │  450     │ │  600     │ │
│  │          │ │          │ │ (효과)   │ │
│  │ [선택]   │ │ [선택]   │ │ [선택]   │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│                                          │
│  스킵 보상: $3        스킵 보상: 태그    │
└──────────────────────────────────────────┘
```

- **3열 레이아웃**: 스몰 / 빅 / 보스 블라인드를 카드 형태로 나열.
- 각 카드: 블라인드 이름 + 목표 점수. 보스는 특수 효과 명시.
- 스몰/빅은 스킵 가능, 스킵 시 보상(돈 또는 태그) 획득.
- 보스는 스킵 불가.

## (d) 게임오버 / 승리 화면

### 발라트로 원본

- **게임오버**: 어두운 배경 + "Game Over" 텍스트 + 최종 도달 앤티/라운드.
  재시작 버튼 1개.
- **승리**: 앤티 8 보스 클리어 시 축하 연출 + 최종 점수 + 보유 조커 목록.
  재시작 버튼.
- 둘 다 단순 — 카드 하나 없는 텍스트 화면.

## 고스트로 적용 변환 메모

### 핵심 대응

| 발라트로 | 고스트로 | 비고 |
|---|---|---|
| 포커 카드 52장 | 화투 카드 (홍단/청단/초단/고도리/피) | 월 숫자 없음, 종류만 |
| 포커 족보 (페어, 플러시 …) | 단 / 고도리 / 피 | `game/hwatu.lua` |
| 조커 슬롯 | 광 슬롯 (★) | 최대 5칸, 상점 구매 |
| 핸드 5장 선택 | 핸드 5장 선택 | 동일 |
| $→$ | $→$ | 소지금 동일 |

### 320×180 기준 좌표 스케치

```
320×180 해상도 매핑:

Y=0─16   : 광 조커 슬롯 (24×36 카드 × 5, 간격 4px)
           x: 44, 72, 100, 128, 156  (가운데 정렬)

Y=20─50  : 점수판 (좌: x=4, w=72, h=30)
           블라인드 목표 (우: x=244, w=72, h=30)

Y=100─110: 플레이/버리기 버튼 (가운데, 각 w=48 h=14, 간격 8)
           플레이: x=108, y=100
           버리기: x=164, y=100

Y=120─156: 핸드 카드 8장 (24×36, 간격 = 16px 겹침)
           첫 카드 x=32, 이후 +16px씩
           선택 시 y -= 8px

카드 크기: 24×36 px (2:3 비율, 320×180에 최적)
```
